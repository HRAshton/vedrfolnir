# Vedrfolnir 0.3.0  -  proposed release notes

**Unreleased.** These notes describe the candidate changes on the release-readiness
PR. No release/tag/PyPI distribution is created by this PR. The published v0.2.0
release remains unchanged.

## Changes since v0.2.0

- Existing `master` contains job-level monitoring and API additions and improved
  source ingestion; see the recorded October 2026 experiment notes.
- Add `vedrfolnir doctor` and `vedrfolnir serve` for local checks and serving.
  Keep Docker Compose as the documented deployment route.
- Add CSV and SQL Server example fixtures, read-only source mounts and
  detailed deployment walkthroughs in the repository.
- Refuse known placeholder `ETA_ADMIN_TOKEN` values at application startup.
- Track the existing additive SQLite upgrade as schema v1 and refuse databases
  stamped with a newer unknown version.
- Wait for a running poll thread before disposing storage at shutdown.
- Align contributor instructions with local-only validation; move optional
  benchmark wrappers into `scripts/benchmarks/`.

## Before publishing

Run `bash scripts/local_check.sh full` on CPython 3.15 with actual River and
`bash scripts/local_check.sh docker` where Docker is available, check packaging
in an isolated wheel environment, review schema/rollback/accuracy evidence,
and then explicitly authorize a release commit, tag, and publication.
These actions are **not** performed by this PR.

## Follow-up design work

Define a retention/archiving policy for historical runs and plan snapshots,
evaluate overlapping import watermarks with idempotent replay, and supply a
reviewed authenticated TLS reverse-proxy deployment. A dependency lock for
CPython 3.15 and wider lint coverage also need a separately verified update.
